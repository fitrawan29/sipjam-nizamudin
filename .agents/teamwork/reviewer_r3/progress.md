## Audit Findings & Fixes in Round 3
1. **Multi-Religion Fallback Attendance Collision in KBM Journals**:
   - **Mechanism**: `resolveDailyStudentAttendance` and `findLastKbmJournal` in `src/lib/presensiIntervensi.ts` did not verify whether a student was eligible for a religion-specific KBM teaching journal.
   - **Vulnerability**: In a class where both PAI and PAK were held, `findLastKbmJournal` returned whichever journal was sorted first. If a PAI journal had `isSemuaHadir` ("Hadir Semua"), a Christian student inherited "Hadir" from a PAI journal. If a Christian student was Alfa in PAK at the same hour, the Christian student's absence was eclipsed and missed.
   - **Surgical Fix**:
     - Updated `findLastKbmJournal(journals, student?)` to optionally filter candidate journals strictly by student subject eligibility (`isStudentEligibleForSubject(student, j.mapel)`).
     - Guarded `resolveDailyStudentAttendance` so that if `lastKbmJournal` is a religion-specific subject and the student is ineligible, `activeJournal` is nullified, granting complete immunity across religions.
     - Updated `RekapSiswaView.tsx` (lines 241, 315, 690) to pass student context to `findLastKbmJournal(journals, s)`.

2. **Polymorphic String & Case Variation Resilience in Religion Evaluators**:
   - **Mechanism**: `isIslamStudent` and `isKristenStudent` assumed an object with lowercase properties (`agama`, `status_agama`, `religion`).
   - **Vulnerability**: Passing a direct string (e.g. `'Islam'`, `'Kristen'`) or an unnormalized object with capitalized keys (`{ Agama: 'Islam' }`, `{ Religion: 'Catholic' }`) failed evaluation.
   - **Surgical Fix**: Updated `isIslamStudent` and `isKristenStudent` in `src/lib/agamaFilter.ts` to accept `student?: ... | string | null` and extract `(student as any).Agama || (student as any).Religion`.

3. **CSV Template Schema Completeness in `AdminDataView.tsx`**:
   - **Mechanism**: `Template_Data_Siswa.csv` generated by `handleDownloadTemplate` omitted the `agama` column.
   - **Vulnerability**: Administrative staff downloading the official template had no `agama` column header to fill in for student batch imports.
   - **Surgical Fix**: Added `'agama'` to headers and `'Islam'` to sample row in `Template_Data_Siswa.csv`.

4. **Regression Proof Expansion**:
   - Added 2 new comprehensive test cases in `tests/agama_pai_pak_isolation.test.ts` (bringing total checks from 27 to 29):
     - Check 28: Polymorphic string and case-insensitive object key evaluation.
     - Check 29: Parallel KBM journal resolution isolation, truancy bolos inheritance, cross-religion immunity, and general subject non-regression.
