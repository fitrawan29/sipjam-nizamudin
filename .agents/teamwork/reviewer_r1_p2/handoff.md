# Adversarial Review & Handoff Report: Master Data Guru CSV Import `sekolah_id` Validation

> [!WARNING] **Skepticism Disclaimer**
> Confidence is high in CSV pre-validation and UUID constraint enforcement across comma and semicolon formats, though live multi-tenant school ID cross-matching and multi-thousand row browser memory usage remain unbenchmarked.

---

## 1. What the prior attempt got wrong

### Issue 1: Non-UUID `sekolah_id` bypassed null check and triggered PostgreSQL 22P02 error
- **Input:** CSV containing non-empty, non-null, but invalid UUID `sekolah_id` (e.g. `'school123'`).
- **Expected:** Pre-validation catches invalid UUID format with a clear localized error `Baris 1: Format "sekolah_id" ("school123") tidak valid. Harus berupa format UUID (contoh: "a0000000-0000-0000-0000-000000000001").` before database insertion.
- **Actual:** Prior code only checked for truthiness and literal `"null"`/`"undefined"`, passing `'school123'` directly to Supabase upsert which crashed PostgreSQL with unhandled database error `22P02: invalid input syntax for type uuid: "school123"`.
- **Root cause:** Missing UUID regex format validation in `parseAndValidateMasterCsv` for `sekolah_id`.

### Issue 2: Semicolon-delimited CSVs (standard Indonesian / European Microsoft Excel export format) failed validation
- **Input:** CSV with semicolon `;` delimiters (e.g. `sekolah_id;nip;nama_guru;mata_pelajaran`).
- **Expected:** Delimiter autodetected or parsed properly so `sekolah_id` is recognized and imported.
- **Actual:** `parseCsvLine` only parsed comma `,`, producing a single column `sekolah_id;nip;...`, causing `sekolah_id` to be reported missing and throwing a false validation error on row 1.
- **Root cause:** Hardcoded comma delimiter in `parseCsvLine` without delimiter autodetection.

### Issue 3: Trailing empty delimiter rows (e.g. `,,,,,,` or `;;;;;;`) triggered false validation errors
- **Input:** CSV with trailing empty lines containing delimiter characters generated by spreadsheet exports.
- **Expected:** Empty trailing lines skipped gracefully.
- **Actual:** Condition `vals.length === 0 || (vals.length === 1 && vals[0] === '')` treated `['', '', '', ...]` as an actual record and threw `Baris X: Kolom "sekolah_id" wajib diisi...`.
- **Root cause:** Row skip condition failed to check if all row values were empty/whitespace strings.

### Issue 4: Invisible Unicode BOM / zero-width characters in headers bypassed alias mapping
- **Input:** UTF-8 BOM `\uFEFF` before quoted headers (e.g. `"\uFEFFsekolah_id"`).
- **Expected:** BOM stripped and header normalized to `sekolah_id`.
- **Actual:** Header retained `\uFEFF`, failed exact match, and caused `sekolah_id` to be treated as missing.
- **Root cause:** Header sanitizer stripped spaces and dashes but not zero-width/BOM characters `[\u200B-\u200D\uFEFF]`.

## 2. What I changed

1. **`src/lib/dataIntegrityGuard.ts`**:
   - Added customizable delimiter parameter `delimiter = ','` to `parseCsvLine(line, delimiter)`.
   - Added automatic delimiter detection (detecting semicolon vs comma) in `parseAndValidateMasterCsv` for Indonesian Excel compatibility.
   - Added zero-width/BOM character removal in `normalizeCsvHeaders` and expanded aliases (`sekolahid`, `schoolid`, `idsekolah`, `sekolah_uuid`, `uuid_sekolah`).
   - Added strict UUID validation `UUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;` for `sekolah_id` in `data_guru` and other tables.
   - Fixed empty row skipping with `vals.every(v => !v || v.trim() === '')`.
   - Hardened `row.id` check against string literals `"null"` and `"undefined"`.

2. **`tests/data_guru_csv_import_sekolah_id_validation.test.ts`**:
   - Added Test 1.6: Non-UUID `sekolah_id` (`'school123'`) pre-validation rejection.
   - Added Test 1.7: Trailing empty delimiter row skipping.
   - Added Test 2.2: Mock DB verification preventing PostgreSQL 22P02.
   - Added Test 3.2b: Extended aliases (`sekolahid`) and BOM normalization.
   - Added Test 3.2c: Semicolon-delimited Indonesian Excel CSV import verification.
   - Expanded test suite from 10 to 15 passing tests.
